# نخبة — Flutter أصلي (النسخة 3.1)

نفس تطبيق الموقع (v23) مبنيّاً بـ Flutter، ويتصل بنفس قاعدة Supabase.

## ما فيه الآن
- صفحة ترحيب بصورة الشعار (تظهر عند كل فتح، وتختفي بعد ثانية ونصف أو باللمس).
- الصفحة الرئيسية بنفس تصميم الموقع: صندوق الصور المتحرك (20 صورة + صور يضيفها المدير)، لوحة الإعلانات، فقاعات: الرؤية، الرسالة، الإدارة، المعلمون، الطالب، رأيك، ورابط الخصوصية، وزر الوضع الداكن.
- قائمة الطالب: الجداول (دراسي + امتحانات)، مهماتي (صف + شعبة)، منظم الدراسة (مهام، مؤقت، تقدم، وسام أسبوعي، روزنامة)، الترفيه (أسئلة سرعة 100 سؤال + لعبة الذاكرة)، طمأنينة، المعلمون والمعلمات.
- بطاقات الكادر بتبويباتها (معلمون، معلمات، مساعدو المدير، الديوان، مرشدون، أمين المكتبة، محاسبون، ممرضات) مع:
  العلاقات الدراسية (صفوف + شعب) • المهام والاختبارات (صفوف/شعب + صور حتى 10) • إعلانات المساعد • الكتب المستعارة • طمأنينة (للطالب، ولوحة المرشد + ملصق QR + طلبات الدعم).
- المدير: إضافة كادر مع حساب (دالة manage-user) • حذف • تغيير كلمة السر • تعديل البطاقة • إدارة الإعلانات • صور المعرض.
- سهم الرجوع: زر "رجوع" داخل كل صفحة، والسهم العائم أعلى اليسار يظهر بعد التمرير.

## لم يُنقل
- اللغة الإنجليزية.
- تحميل صور المهام على الجهاز (حالياً تُعرض وتُكبَّر فقط).
- الطباعة المباشرة للملصق (التقط صورة للشاشة).

## البناء على GitHub (بدون تثبيت Flutter)
ارفع محتويات المجلد كما هي (يجب أن يظهر `pubspec.yaml` و`lib/` و`.github/` في جذر المستودع).
ثم: تبويب Actions ← Build APK ← Run workflow. بعد انتهائه نزّل الملف من Artifacts باسم `nokhba-apk`.

> الكود لم يُختبر بالبناء (لا يوجد Flutter عند كاتبه). عند أول بناء قد تظهر أخطاء بسيطة؛ أرسل نص الخطأ من تبويب Actions ليُصلَح.

## بنية الكود
`lib/main.dart` (الإعدادات، الجلسة، شاشات الدخول/الجداول/مهماتي/طمأنينة) + `lib/parts/`:
`shell` (الثيم والسهم) • `landing` (الترحيب والرئيسية والمعرض) • `menu` • `fun` + `quiz_data` • `organizer` • `panels` • `staff`.
