# نخبة — Flutter أصلي

## التشغيل
```bash
flutter create --platforms=android,ios --project-name nokhba .   # يولّد مجلدي android/ و ios/ (لا يمسّ lib/)
flutter pub get
flutter run
```
المتطلبات: Flutter 3.27 أو أحدث. بعد `flutter create` راجع `android/app/src/main/AndroidManifest.xml`
(الملف المرفق فيه الاسم "نخبة" وصلاحية الإنترنت)، وأضف لـ iOS صلاحية الصور (`NSPhotoLibraryUsageDescription`).

## المربوط حالياً بقاعدة Supabase الموجودة
الدخول (معلم / إدارة) • الإعلانات • الجداول والامتحانات (قراءة وتعديل للمدير) • مهامي (RPC) •
المعلمون وبطاقتي (عرض + تعديل) • المكتبة • طمأنينة + لوحة المزاج • التواصل مع المرشد • تغيير كلمة السر.
منظم الدراسة محلي على الجهاز.

## لم يُنقل بعد
معرض الصور • إضافة/حذف المعلمين وإعادة تعيين كلمة السر (دالة `manage-user`) •
تحرير المعلم لمهامه وصفوفه وإعلاناته • تقويم المنظم والإنجاز الأسبوعي • ماذا نعرف (الأسئلة والذاكرة) • الملصق وQR.

## قاعدة البيانات
`supabase/schema.sql` مخطط مُستنتَج من الكود (للمرجع أو لمشروع جديد). تحقق منه مقابل قاعدتك الفعلية.
لاستخدام مشروع جديد غيّر القيم في `lib/core/config.dart`.

## البناء على GitHub (بدون تثبيت Flutter)
ارفع محتويات المجلد كما هي (يجب أن يظهر `pubspec.yaml` و`lib/` و`.github/` في جذر المستودع).
ثم: تبويب Actions ← Build APK ← Run workflow. بعد انتهائه نزّل الملف من Artifacts باسم `nokhba-apk`.

## تصميم نخبة (نسخة الموقع)
- صفحة ترحيب: اسم المدرسة بخط Aref Ruqaa، رؤية ورسالة بسهم، إعلانات، وبوابات فقاعات متحركة (طالب / معلمون / إدارة).
- خلفية شعار المدرسة بلور خفيف، وسهم رجوع عائم ثابت.
- قوائم الفقاعات بكركترات (`assets/images/`).
- بعد التحديث: `flutter pub get` (حزمتا google_fonts و flutter_svg جديدتان).
